# Poly Haven density texture

Asset: **Aerial Rocks 02** (`aerial_rocks_02`).

- Source: https://polyhaven.com/a/aerial_rocks_02
- Asset licence: CC0, https://polyhaven.com/license
- Retrieved using ahujasid Blender MCP's dedicated Poly Haven import tool on 10 September 2026.
- Included source: `horizon-assets/polyhaven/aerial_rocks_02_disp_1k.jpg`.

The displacement map supplies a small part of the corona's irregular density.
The official Blender MCP was used to construct native procedural materials,
sample them with Cycles, export the optical geometry and save an editable scene.
The numeric field is bundled for offline browser use. The imported source maps
are packed in `continuous-horizon.blend`.

This is a transformed texture contribution, not a premade black-hole or aura
asset. The user-supplied reference images are not incorporated into the output.
